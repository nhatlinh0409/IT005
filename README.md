Repository này lưu trữ các bài tập thực hành (Lab), mô phỏng mạng Cisco và các bài phân tích gói tin Wireshark của môn học IT005 - Mạng máy tính.

- `/WIRESHARK`: Chứa các bài thực hành bắt và phân tích gói tin mạng bằng Wireshark (các file `.pcapng`), báo cáo bài tập nhóm và các bài tập lý thuyết làm trên lớp.
